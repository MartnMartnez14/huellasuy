# Roadmap
- v0.1: Flask, SQLite y mapa.
- v0.2: publicación, ubicación y expiración.
- v0.3: tokens, seguridad, pruebas y accesibilidad (prototipo actual).
- v1.0: despliegue público verificado, revisión de proxy y monitoreo.
- v1.1+: evaluar fotos optimizadas, PWA, clustering, PostgreSQL y moderación. No implementados en esta versión.

- Segunda versión: validar pertenencia a Uruguay con límites geográficos reales y revisar puntos fronterizos. El prototipo solo advierte mediante coordenadas aproximadas; no bloquea publicaciones fuera del país.

## Entrega v2.0 (10 de octubre de 2026)
Cuentas verificadas, recuperación, emoji persistente, acceso restringido al mapa/API, autor asociado internamente y administración por correo verificado. Código listo para despliegue manual y prueba de enlaces reales; no afirmar activación pública hasta confirmarla. Se conservan 24 horas. Fotos, comentarios, contactos, denuncias y duraciones 48 horas/siete días quedan para entregas posteriores.
